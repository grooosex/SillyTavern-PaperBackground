# 纸色背景

给 SillyTavern / TauriTavern 用的浅色背景扩展。

纯色比原来多一排：绘语米、米纸、暖白、燕麦、浅杏、豆沙、石灰、墨灰、暖灰、淡松绿、茶绿、青瓷、雾青、雾蓝、远山蓝、海蓝、灰紫，也可以自己取色。绘语米是 `#F0EAE4`。米纸 `#F0E8DD` 还在。

也可以上传一张图，按当前窗口比例裁好，铺在聊天区后面。顶栏和输入栏保持纯色。

浅底自动把主文字改成近黑，深底改成浅色。引用色默认不动。斜体只有太浅时才压成灰色 `#5E5953`，不会改成和正文一样的黑。

## 整套主题

勾上「启用整套主题」之后：

- 如果当时还停在旧的米纸，会切到绘语米一次。之后再换底色，主题不会把底色抢回去。
- 强调色默认是灰砖红 `#905448`，也可以换成朱砂、松绿、雾蓝、藕紫这些，或自己取色。
- 没选中的顶栏图标是暖灰，选中的图标本身变成强调色，不再垫一块黑底。
- 铺满的按钮、勾选框、滑条用强调色。标题条是强调色混进纸色的浅渐变，最深不超过强调色本身，不再往黑色里混。条上的字是近黑。
- 聊天消息上的笔、眼睛、三个点，只要开着纸色就不再用酒馆那层三成透明和黑色投影。实色暖灰，按住变成近黑。关掉纸色后恢复。
- 金黄对白加斜体。关掉主题后斜体去掉。主文字颜色和引用色随时能改，主题不会锁住。
- 第一次打开时，如果还没改过字体，正文会用系统黑体、字重 400。之后你改的字体、字号、粗细会留下来。关掉再打开主题，不会把这次的字体修改盖掉。

强调色很浅时，铺满的按钮上改用黑字，避免白字看不清。中文在很多手机上没有斜体字形，对白可能只是略微倾斜。

正文字体可以选酒馆默认、系统黑体、系统宋体，或填写这台设备里已经有的字体名。不能上传字体文件。字号和粗细只作用于聊天正文。安卓上 300 和 400 有时看不出差别。

关掉「启用」，或者在扩展管理里禁用，界面回到酒馆原来的主题，不会改你的主题文件。

## 安装

扩展面板 → 安装扩展，粘贴：

```
https://github.com/grooosex/SillyTavern-PaperBackground
```

已经装过的，在扩展里更新这个扩展，然后刷新页面。设置面板里要能看到「启用整套主题」和「强调色」，才是这一版。

仓库需要保持公开。TauriTavern 只用匿名 https 地址安装。
