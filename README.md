# 纸色背景

给 SillyTavern / TauriTavern 用的浅色背景扩展。纯黑底可以换成米纸、暖白、淡松绿、雾蓝、暖灰，或自己选的颜色；也可以上传一张图，按当前窗口比例裁好，铺在聊天区后面。

顶栏、输入栏、扩展抽屉和聊天区会一起变成这个浅色。图标跟着主文字变深，不会留在白字上看不见。

浅色底会自动把主文字改成近黑 `#1A1814`，深色底改成浅色。也可以自己指定主文字颜色，指定之后自动让路。

引用色默认不动。金黄对白还是原来的颜色。需要的话再勾「自己指定」。

斜体只有在新背景上太浅、看不清的时候，才会压成灰色 `#5E5953`，不会改成和正文一样的黑。引号里面的斜体仍跟着引用色。下划线只有浅到几乎看不见时，才同样改成这档灰色。

关掉扩展里的「启用」，或者在扩展管理里禁用，都会回到酒馆原来的主题，不会改你的主题文件。

## 安装

扩展面板 → 安装扩展，粘贴：

```
https://github.com/grooosex/SillyTavern-PaperBackground
```

仓库需要保持公开。TauriTavern 只用匿名 https 地址安装，私有仓库和 SSH 地址不行。

装好后在扩展列表里打开「纸色背景」，点进去勾上启用。米纸预设就是一张偏暖的 `#F0E8DD`。

图片会压成一张不太大的 jpg 存在酒馆设置里。淡化滑杆越高，聊天区越接近纯色，字越好读；顶栏和输入栏始终是纯色。
