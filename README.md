# 纸色背景

给 SillyTavern / TauriTavern 用的浅色背景扩展。纯黑底可以换成米纸、暖白、淡绿、雾蓝、暖灰，或自己选的颜色；也可以上传一张图，裁成当前窗口的比例当背景。

浅色底会自动把主文字改成墨色，深色底改成浅色。你也可以自己指定主文字颜色。

引用色默认不动。金黄对白还是原来的颜色。需要的话可以另开「自己指定引用色」。

斜体只有在新背景上太浅、看不清的时候，才会改成灰色，并且和主文字错开。引号里面的斜体仍跟着引用色。

关掉扩展里的「启用」，或者在扩展管理里禁用，都会回到酒馆原来的主题，不会改你的主题文件。

## 安装

扩展面板 → 安装扩展，粘贴：

```
https://github.com/grooosex/SillyTavern-PaperBackground
```

仓库需要保持公开。TauriTavern 只用匿名 https 地址安装，私有仓库和 SSH 地址不行。

装好后在扩展列表里打开「纸色背景」。
